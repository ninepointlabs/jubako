Jubako

じゅうばこ · joo-bah-koh

noun Lacquered boxes that stack into one. One file, several tables.

Microsoft Access, without the hard parts.

Download 0.4.3 View on GitHub

Spreadsheet chaos?

orders_FINAL_v7.xlsx or orders (2).csv? Which one is right?

Put them in one box. Make a database (or start from a template), put a spreadsheet in it, find the rows you need, print a tidy list. No SQL to learn, no server to set up, no account to make.

一Bring your spreadsheets

Drop a CSV or Excel file on the window. Jubako works out each column (words, whole numbers, decimals, dates, yes/no) and shows you its guesses before anything is written. A workbook with several sheets can become one table per sheet.

二One box. Many tiers.

A database is one .jubadb file: copy it, back it up, email it. Save a copy from the Database menu, even while it's open. It's ordinary SQLite, so nothing is locked away. Already run PostgreSQL or MySQL? Point Jubako there instead.

三Start from a template

Contacts, Inventory, Projects and tasks, Customer service, Home collection. Each comes with its tables, saved views and reports, and a few made-up example rows if you want them. Tables that belong together come connected: each task points at its project, each ticket at its customer, each item at its supplier.

四Browse. Sort. Edit.

A grid of everything in a table. Tap a heading to sort by it, double-tap a cell to change it. Add, rename or delete a field; mark one “no repeats”, like an email or a product code. The destructive ones ask first.

五Ask your rows a question

“Show rows where Category contains bike and Status is Delivered” hides the rest. Compare numbers and dates (“is more than 3000”, “is after 2026-03-31”), match all rules or any. Save what you keep using as a view, sort and all, and it lives inside the database file.

六Connect your tables

A lookup field points at a row of another table: an order's Item is a row of products. Rename a product and every order shows the new name. Turn a column of names into a lookup in one step; Jubako lists any name that matches nothing and can add it for you. A product that orders still point at cannot be deleted by accident.

七All of them at once

Do something with the rows you found: change a field in every one (“set Paid to Yes”), delete them, or see what they add up to, with totals, averages, earliest and latest. Jubako says how many rows first.

八One record at a time

A form for every table. Previous, Next, Save, New row, Duplicate. Arrange it: the order of the fields, what each is called, which to leave out. Hidden fields keep their values.

九Reports that fit the page

Pick the columns, a title, the page size. Sort it, group it with a heading per group, total the number columns, add your own header and footer, or print straight from a saved view. Columns shrink and wrap so the whole table fits, and what you see is what prints. Export to CSV, Excel or PDF.

十Wears your theme

Jubako reads your Omarchy theme and follows it, dark or light, with your accent colour. Change theme and the open window changes with it.

十一Let your agents in

An MCP server (37 tools) and a command line do the same jobs as the window: templates, rules and sorts, lookups between tables, changing many rows at once, grouped reports. A misspelt argument is refused, never quietly ignored. “Turn this spreadsheet into a database” just works from Claude Code or any MCP client.

jubako
$ jubako new "Harbor Cycles" harbor-cycles
$ jubako import harbor-cycles.jubadb book.xlsx --all-sheets
$ jubako rows harbor-cycles.jubadb orders --filter total more_than 3000 --sort total:desc
$ jubako lookup harbor-cycles.jubadb orders item --to products --show product
$ jubako set harbor-cycles.jubadb orders paid yes --filter status is Delivered
$ jubako report harbor-cycles.jubadb orders sales.pdf --view "Bike sales" --group-by rep --total total:sum
$ jubako new "Bike stock" stock --template inventory
# or let an agent drive it: claude mcp add jubako -- jubako-mcp

Install

Packages for Arch and Omarchy, Debian and Ubuntu, and Fedora. They use your distro's Python and Qt, and put Jubako in your app launcher.

Arch · Omarchy

sudo pacman -U jubako-0.4.3-1-any.pkg.tar.zst
Download .pkg.tar.zst

Debian 13+ · Ubuntu 26.04+

sudo apt install ./jubako_0.4.3-1_all.deb

Fedora 44+

sudo dnf install ./jubako-0.4.3-1.noarch.rpm
